This repository is for calibrating a Nortek [Signature 100 echosounder](https://www.nortekgroup.com/products/signature100) using standard sphere calibration techniques. This is not for calibrating the ADCP. This code was originally written by George Cutter and Sven Nylund in 2019 and 2020.

The notes for this repo are [here](ADCP_calibration_code_notes.md)
